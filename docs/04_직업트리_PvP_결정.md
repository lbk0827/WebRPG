# ADR-003. 직업 트리 깊이와 PvP 비중

- **상태**: 채택 (Accepted)
- **결정일**: 2026-09-09

---

## 1. 직업 트리 깊이 → 2단 유지, 폭으로 확장

### 결정
1차 직업 계통 4개 → 각 2~3개의 2차 직업. **3단 전직은 만들지 않는다.**

### 근거
**이 게임의 깊이는 직업이 아니라 수칙에서 나온다.**
같은 직업 구성으로도 완전히 다르게 플레이할 수 있다는 것이 이 장르의 존재 이유다.
복잡도 예산을 직업 트리에 쓰면 정작 깊이가 나와야 할 곳이 아닌 데 쓰는 셈이 된다.

또한 5인 편성 × 수칙 조합만으로 이미 밸런싱 부담이 크다.
직업 단계를 하나 더 얹으면 검증이 불가능해진다.

### 대신 하는 것 — 직업마다 "수칙 훅"

스탯 차이가 아니라 **수칙 설계 방식의 차이**를 만든다.
각 2차 직업은 특정 조건 타입을 활용해야 진가가 나오도록 설계한다.

| 훅 유형 | 설계 방향 |
|---|---|
| 끊기 특화 | *"적이 시전 중"* 조건을 활용해야 강해짐 |
| 순서 조작 | 행동 게이지를 조작해 아군의 행동 순서 자체를 설계하게 함 |
| 전황 변형 | 소환으로 *"아군 수" / "소환수 수"* 조건의 지형을 바꿈 (M1 제외, 후속) |
| 정밀 지휘 | 패턴 슬롯이 유독 많아 정교한 지시를 감당 |

직업 수를 늘리지 않고도 수칙 설계 공간이 넓어진다.

### 유보
3차 전직은 엔드게임 목표로 후속 검토. **M1에는 직업 시스템 자체를 넣지 않는다**
([05_M1_전투엔진_명세.md](05_M1_전투엔진_명세.md) 참조).

## 2. PvP 비중 → 투기장은 정체성, 토벌 의뢰는 리텐션

### 결정
둘 다 만든다. 역할이 다르다.

| | 투기장 (비동기 PvP) | 토벌 의뢰 (협동 PvE) |
|---|---|---|
| 역할 | **게임의 정체성 / 마케팅 훅** | **매일 접속할 이유** |
| 개발 비중 | 작음 (사다리라 매치메이킹 불필요) | 큼 |
| 노출 비중 | **큼** — 스토어 첫 스크린샷 | 중간 |
| 대상 | 코어 유저 | 전체 |

### 근거

**투기장 = 마케팅 훅.**
"내가 짠 전술이 다른 사람이 짠 전술과 싸운다" — 이 한 문장이 게임을 판다.
PvE만 있으면 오토배틀러 하나 더에 불과하다.
사다리 방식이라 매치메이킹 로직이 필요 없어 구현 비용도 낮다.

**토벌 의뢰 = 리텐션.**
순수 PvP 사다리는 초보에게 가혹하고, 초기 인구가 적으면 죽은 것처럼 느껴진다.
협동 PvE는 패배가 없고 인구가 적어도 성립한다. 행동력 소모가 적어 "가볍게 한 판" 자리에 맞는다.

### M1 처리
**M1에는 둘 다 넣지 않는다.**
봇 상대로 수칙을 짜는 것만으로 재미가 나오는지가 먼저 판명되어야 한다.
거기서 재미가 없으면 PvP를 붙여도 살아나지 않는다.
