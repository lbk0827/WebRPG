# ADR-002. 세계관 프레임과 톤

- **상태**: 채택 (Accepted)
- **결정일**: 2026-09-09
- **관련 문서**: [01_시스템_명세서_초안.md](01_시스템_명세서_초안.md) 4장

---

## 1. 결정

**정통 판타지 용병단** 세계관을 채택한다.
플레이어는 용병단의 **단장**이며, 전투는 **단원들**이 수행한다.

사전 프로그래밍의 정당화 장치로 **"교전 수칙(Rules of Engagement)"** 개념을 도입한다.

---

## 2. 배경 — 왜 이 논의가 필요했나

이 장르(행동 규칙 프로그래밍 + 자동 전투)는 사실상 판타지 일색이다. 이유는 셋이다.

1. **에셋 경제** — 대부분 개인/소규모 제작이며, 무료·저가 소재가 가장 풍부한 영역이 판타지다
2. **어휘 압축** — HP, 마나, 힐러, 탱커, 전열/후열은 이미 합의된 언어라 설명이 필요 없다.
   이 게임은 "규칙 프로그래밍"이라는 어려운 개념을 이미 가르쳐야 하므로,
   세계관 용어까지 새로 가르치면 학습 부담이 두 배가 된다
3. **혈통** — 장르 자체가 2000년대 일본 웹게임 계보에서 나왔고 그쪽이 통째로 판타지였다

예외는 존재한다. **Gladiabots**(GFX47)는 동일한 메커니즘을 SF 로봇으로 풀어 상업 서비스 중이다.
즉 메커니즘 자체는 장르를 가리지 않는다.

### 진짜 쟁점

세계관 선택의 핵심 질문은 "무엇이 멋있나"가 아니라 이것이었다.

> **왜 플레이어는 전투 중에 직접 조작하지 못하는가?**

이 질문에 세계관이 답하지 못하면, 규칙이 실패했을 때 플레이어의 반응이 달라진다.

| | 플레이어의 해석 | 결과 |
|---|---|---|
| 설명 없음 | "왜 얘가 멍청하게 서 있어?" → **시스템 탓** | 이탈 |
| 설명 있음 | "내가 지시를 잘못 내렸구나" → **내 탓** | 규칙 수정 = 코어 루프 복귀 |

두 번째여야 게임이 돌아간다. 따라서 세계관은 장식이 아니라 **코어 루프를 지탱하는 구조물**이다.

## 3. 검토한 대안

| | A. 정통 판타지 용병단 | B. 마도공학 오토마타 | C. 근미래 드론 지휘 |
|---|---|---|---|
| 프레임 | 사전에 훈련시킨 용병들이 싸움 | 술사가 골렘에 명령 룬을 각인 | 통신 지연으로 사전 프로그래밍만 가능 |
| 조작 불가 정당화 | 자체적으로는 없음 → **4장에서 해결** | 룬 = 규칙 그 자체 | 신호 지연 |
| 어휘 학습 부담 | 없음 | 거의 없음 | 중간 |
| 에셋 조달 | 쉬움 | 중간 | 어려움 |
| 차별화 | 낮음 | 중상 | 높음 |
| 캐릭터 애착 | 높음 | 중간 | 낮음 |
| 리스크 | 평범함 | — | **Gladiabots와 정면 경쟁**, 육성·장비·경제 시스템과 겉돎 |

**A를 채택한 이유**: 학습 부담이 가장 낮고, 육성·장비·경제·투기장이라는 이 게임의 시스템 구성과
가장 자연스럽게 맞물린다. 유일한 약점이었던 "조작 불가 정당화"는 4장의 장치로 해결 가능했다.

C는 차별화가 크지만 이미 점유된 자리이며, 로봇에게 갑옷을 입히고 레벨을 올리는 구성이 어색하다.

## 4. 핵심 장치 — 교전 수칙 (Rules of Engagement)

판타지 용병단 안에서 사전 프로그래밍을 정당화하는 장치.

**설정상의 근거 두 가지**

1. **투기장 규정** — 경기 중 외부 지시는 규정상 금지된다 (실제 검투 경기의 규칙)
2. **야전 통제 한계** — 단장은 후방에 있어 혼전 중 개별 지시가 닿지 않는다

따라서 단장은 **출전 전에 각 단원에게 교전 수칙을 하달**하고, 전투는 그 수칙대로 전개된다.

### 4.1 용어 매핑

> **2026-09-10 변경**: 규칙 한 줄을 부르던 "조항"을 **"패턴"** 으로 통일. 단장이 "조항"의 뜻을 되물었고, 이 장르 유저가 이미 쓰는 말이 "패턴"이다.
> "교전 수칙"은 목록 전체와 세계관 설명문에만 남긴다.

시스템 개념을 세계관 용어로 고정한다. **UI 문구는 이 표를 기준으로 작성한다.**

| 시스템 개념 | 게임 내 용어 |
|---|---|
| 플레이어 | 단장 |
| 캐릭터 | 단원 |
| 파티 | 용병단 / 편성 |
| 행동 패턴 규칙 목록 | **교전 수칙** |
| 규칙 한 줄 | 수칙 패턴 |
| 규칙 슬롯 개수 | 단원이 암기 가능한 패턴 수 → **숙련도로 확장** |
| 조건 | 상황 판단 |
| 규칙 에디터 | 수칙 편성 |
| 샌드박스 시뮬레이터 | **훈련장** |
| 전투 로그 | 전황 보고서 |
| 패턴 프리셋 | 교범 |
| 패턴 공유 | 교범 배포 |
| 콜로세움 | 투기장 |
| 협동 레이드 | 토벌 의뢰 |
| 지역 | 의뢰지 |
| 대장간 | 공방 |
| 경매장 | 거래소 |

### 4.2 이 매핑이 특히 잘 작동하는 지점

**훈련장 = 시뮬레이터**
"훈련은 공짜, 실전은 대가가 있다"가 설명 없이 이해된다.
원본에 없던 기능(행동력 0의 샌드박스)이 세계관 안에서 자연스럽게 정당화된다.

**규칙 슬롯 = 암기 가능한 패턴 수**
슬롯 확장이 캐릭터 성장의 축이 된다. "이 단원은 아직 복잡한 지시를 못 외운다"가 곧 레벨 디자인이다.

**실패 상태의 해석**
조건이 하나도 일치하지 않아 행동하지 못하는 상황이 이렇게 읽힌다.

> **"수칙에 없는 상황이라 단원이 우물쭈물했다."**

시스템의 결함이 아니라 **지시서의 허술함**으로 읽힌다. 3장에서 제기한 문제가 해결된다.

## 5. 톤

**약간 건조하고 유머러스한 톤**을 채택한다. 비장하거나 진지한 톤으로 가지 않는다.

**근거**: 이 게임은 구조적으로 "내 단원이 조건 미스로 몇 턴간 아무것도 안 하다가 죽는" 상황이
빈번하게 발생한다. 이건 버그가 아니라 **의도된 학습 장치**다.

- 진지한 톤 → 그 상황은 그냥 짜증이다
- 건조한 유머 톤 → **웃긴 실패**가 되고, 웃긴 실패는 공유된다

디버깅이 핵심 게임플레이인 게임에서 이건 공짜로 얻는 리텐션이다.
어설픈 용병단은 코미디의 고전적 소재이기도 하다.

**적용 지침**
- 전황 보고서의 문구는 담백하되 가끔 비꼰다
- 단원의 실패를 조롱하지 않는다. **단장(플레이어)의 지시를 놀린다**
- 세계관 자체는 진지하게 유지한다. 톤만 가볍게 간다 (개그 판타지가 아니다)

---

## 6. 유보 사항

- **고유명사(단원명, 스킬명, 아이템명, 지역명)는 아직 확정하지 않는다.**
  명칭과 아트는 데이터 레이어에 두어 M1 이후에도 교체 가능하게 유지한다.
  원본의 고유명사는 쓰지 않는다 — 우리 세계관이 따로 서야 하기 때문이다.
- 아트 방향(2D 도트 / 일러스트 / 미니멀)은 M1 이후 결정한다.
- 지금 확정한 것은 **프레임과 용어 체계뿐**이며, 이것만으로 UI 문구와 튜토리얼 작성이 가능하다.

---

## 7. 재검토 신호

- 투기장(PvP)이 엔드게임의 중심이 아니게 될 경우 → "경기 중 지시 금지" 근거가 약해지므로 정당화 장치 재설계
- 유저 테스트에서 "교전 수칙"이라는 용어가 어렵다는 피드백이 반복될 경우 → 더 평이한 용어로 교체
