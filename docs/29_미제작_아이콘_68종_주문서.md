## 1. 만드는 방법 — 87종과 똑같이

[docs/14 §1](14_리소스_요청서.md)의 규약과 **「JRPG 느낌」 다섯 가지**를 그대로 지킨다. 요약:

1. JRPG 도트풍 **AI 원본** 한 장씩 → `art-source/icons/<종류>/<id>-source.png` (채택본만 커밋)
   - 공통 프롬프트는 [docs/19 §2](19_JRPG_도트_아이콘_생성_기록.md) 문장 그대로 쓰고 끝에 `Subject:` 한 줄을 붙인다. Subject 는 아래 표의 「그릴 것」을 영어로 옮긴다
   - 종류별로 `game icon` → `skill icon` / `inventory item icon` / `passive-trait icon`
2. 변환: `python tools/process-jrpg-icon.py <원본> assets/<종류>/<id>.png` (24×24 · 10색 이하)
3. 검사: `python tools/check-icons.py` 통과
4. **변환본을 손으로 다시 찍어 단순하게 만들지 않는다** (손그림 재작업은 두 번 반려 — docs/14 §9-1)

지켜야 할 것 한 번 더:

- 한 아이콘에 **상징 하나.** 궤적·반짝임을 여러 개 넣으면 24px 에서 잡티가 된다
- **실물을 그린다** — 검·병·부적·모래시계처럼 쥘 수 있는 것, 또는 그것을 쓰는 순간. ＋·X·화살표만 있는 기호 금지
- 가는 물체(날·지팡이·활·화살)는 **2px 이상**
- 글자 금지, 배경 금지(투명)
- 금지 출처: Hall of Fame · 제로식 · 그 소재 사이트 이미지를 보지도 입력하지도 않는다 (docs/14 §0)

### 이미 있는 아이콘과 헷갈리지 않게

새 아이콘 대부분은 기존 아이콘의 **윗단계**다. 같은 계열로 보이되, 나란히 놓았을 때 구별되어야 한다.
각 표의 「구별할 것」 칸에 짝을 적었다. **짝과 나란히 놓은 검수판**을 같이 낸다 (§6).

## 5. 우선순위 D — 4·5등급 제작 장비 16종 + 재료 5종 + 오의 10종

Lv35~50 구간(전직 뒤)에만 나온다. 위를 끝낸 뒤에 한다. 기획 [docs/22](22_만렙50_확장.md).

### 4·5등급은 재질로 통일한다

| 등급 | 테마 | 공통 표식 |
|---|---|---|
| 4 (Lv35~) | 지역마다 다르다 — **모래(태양석)** · **조수(물)** · **룬** | 태양석 = 주황빛 보석 · 조수 = 청록 비늘/물결 · 룬 = 푸른 새김 무늬 |

## 6. 납품

순서: **A(5) → B(23) → C(9) → D(31).** 합계 68종. 묶음마다 따로 커밋하고 검수받는다.

각 묶음마다:

1. `art-source/icons/<종류>/<id>-source.png` — 채택한 AI 원본
2. `assets/<종류>/<id>.png` — `process-jrpg-icon.py` 변환본 (**SVG 는 만들지 않는다**)
3. `python tools/check-icons.py` 통과. 외톨이 경고(35% 초과)는 목록으로 적어 낸다
4. `assets/manifest.json` 의 `skills` · `items` · `traits` 절에 항목 추가 — 기존 항목과 같은 형태. 그러면 `process-jrpg-icon.py --all` 로 다시 뽑을 수 있다
5. `assets/README.md` 원장에 **원본 줄과 변환본 줄을 함께** 한 줄씩 (도구: OpenAI 내장 ImageGen)
6. **검수판** `art-source/icons/order29-<묶음>-proof-1x.png` 와 `-4x.png`
   - 새 아이콘 옆에 §3~§5 「구별할 것」·「윗단계 짝」의 기존 아이콘을 나란히
   - 밝은 바탕 · 어두운 바탕 두 줄. 배율은 최근접 정수(1배 · 4배)만
7. [docs/19](19_JRPG_도트_아이콘_생성_기록.md) 에 절을 하나 더해 생성 ID 와 결과를 적는다
8. `node tools/build-preview.mjs` 로 미리보기 갱신

**웹 코드는 건드리지 않는다.** id 는 이미 게임에 들어가 있어 파일만 놓이면 `Icon.tsx` 가 알아서 붙인다.
