# 주인공 — 모험가

작성일: 2026-09-14. 새 게임을 **주인공 한 명**으로 시작하는 변경의 결정·임시값·측정·리소스 주문.

---

## 1. 단장 결정

> 게임 처음 시작할 때 현재는 프로토타입(테스트용)이니까 용병을 다 주고 있는데, "모험가"라는 캐릭터 1개만 주도록 하죠.
> 이 모험가라는 캐릭터는 해고가 불가능하고, 주인공의 캐릭터입니다. 처음 계정을 생성할 때, 남자 or 여자 둘 중 하나를 성별을 선택해서 고르게 하고싶어요.
> 이 모험가(남) 모험가(여) 캐릭터의 리소스도 필요하겠군요.

| 물음 | 답 |
|---|---|
| 모험가는 어떤 직업인가 | **고유 직업.** 나중에 **영웅** 클래스로 전직하도록 기획 예정. 무기는 미정 — 모든 무기를 쓰면 스프라이트 제약이 크다. **모험가 전용 성장 무기**(특정 재료로 성장)를 검토 중 |
| 성별은 무엇을 바꾸나 | **외형만.** 능력치·스킬은 같다 (HOF 도 고용 때 성별로 그림만 갈랐다) |
| 혼자면 첫 지역을 못 넘는다 | **첫 지역을 1인용으로 + 시작 금 증액** |
| 지금 테스트 세이브 | **그대로 둔다.** 새로 시작할 때만 적용 |

## 2. 들어간 것

| 곳 | 내용 |
|---|---|
| 새 게임 화면 | 저장이 없거나 본부의 "새 게임"을 누르면 나온다. **성별(남/여) · 이름** → 모험 시작. 본부에서 들어왔으면 취소로 지금 진행에 돌아간다 — 시작을 누르기 전에는 저장을 덮지 않는다 |
| 시작 | 모험가 한 명(`id: hero`, `hero: true`, `gender`), **금 300** (전에는 5직업 + 금 200) |
| 해고 | 주인공은 해고 버튼이 잠긴다. `dismissMember` 도 거부한다 |
| 고용 | 모험가는 용병소 목록(`HIRE`)에 없다. 용병소·본부 할 일·마을 요약이 `PRESETS` 대신 `HIRE` 를 본다 |
| 그림 키 | `adventurer-male` / `adventurer-female` (`memberIcon`). 전투 도트도 같은 키로 고른다 |
| 기존 세이브 | 그대로 불러온다. 주인공이 없는 세이브도 문제없이 돈다 |

## 3. 임시인 것 ⚠

단장 기획이 끝나면 바꾼다. 코드에 `docs/20` 주석으로 표시해 두었다.

| 무엇 | 지금 | 정해질 것 |
|---|---|---|
| 무기 | **어떤 무기도 못 든다** (`JOB_WEAPONS.adventurer = []`). 방어구·장신구는 든다 | 전용 성장 무기? |
| 스탯 | HP 520 · SP 70 · 힘 46 · 지능 20 · 손재주 40 · 속도 48 · 운 20 · 방어 18 · 마방 12 — 무기 없는 만능형 | 무기 결정 뒤 재조정 |
| 시작 스킬 | 기본 공격 · 강타 · 연타 | 고유 스킬 |
| 배울 스킬 | 굳히기 2 · 휩쓸기 3 · 흔들기 3 · 치유 3 | 고유 스킬 |
| 전직 | 없음 | **영웅** |
| 그림 | 남 = 전사 도트, 여 = 도적 도트를 빌려 쓴다 (`labels.ts` 의 `ART_STANDIN`) | Codex 주문 (§5) — 도착하면 그 줄을 지운다 |

## 4. 초반 흐름 — 측정 (시드 200)

주인공은 주 스탯(힘)에 포인트를 넣고 기본 수칙.

| 편성 | 마을 외곽 2~3명 (전) | 마을 외곽 1~2명 (후) | 가도 |
|---|---|---|---|
| 모험가 혼자 Lv1 | 30% | **78%** | 0% |
| 모험가 혼자 Lv2 | 53% | **97%** | 0% |
| 모험가 혼자 Lv5 | 55% | 99% | 0% |
| 모험가 Lv3 + 전사 · 프리스트 (Lv1) | — | — | 48% |
| 모험가 Lv5 + 전사 · 프리스트 (Lv3) | — | — | 65% |

- 2~3명이면 혼자서는 **레벨을 올려도 55% 에 막혔다** — 셋에게 둘러싸이면 끝난다. 그래서 인원을 1~2명으로 줄였다. 5인 편성에는 원래 쉬운 지역이라 영향이 없다
- **가도부터는 혼자 못 간다** (0%). 그게 맞는 모양이다 — 첫 지역에서 3승(가도 해금 조건) 하는 동안 동료를 들이게 된다
- 시작 금 300 = 전사(120) + 프리스트(160). 첫 동료 둘을 바로 들일 수도, 몇 판 모아서 고를 수도 있다
- `balance.test.ts` 가 "혼자 Lv1 ≥60% · Lv2 ≥85%" 를 감시한다
