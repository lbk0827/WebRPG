- **작성일**: 2026-09-10
- **성격**: 시스템과 화면 구성의 관찰 기록.
- **목적**: M2(육성·장비·경제) 설계와 M2-0(전투 기반 보강)의 입력

## 0. 소스 코드에 대하여

**제로식 소스는 공개된 적이 없다.** 원 HOF 소스를 개조해 운영하는 사설 서버이며(저작권 분쟁 후 일본 서버로 이전),
소스가 있더라도 HOF 파생물이라 **비상업 규약을 그대로 물려받아 우리가 쓸 수 없다.**
→ 게임을 플레이어 관점에서 관찰하는 것이 유일하게 합법적이고, 설계에는 그것으로 충분하다.

## 1. 제로식 HOF — 원본이 15년 운영되며 어디까지 갔는가

> 출처: 나무위키 "Hall Of Fame(제로식)" 및 "/직업" (2026-08 기준), 인벤·오유 소개글

제로식은 **원본 HOF 위에 15년치 콘텐츠를 쌓은 것**이다. 우리에게는 "이 장르가 오래 굴러가면 무엇이 필요해지고 무엇이 망가지는가"의 실증 자료다.

### 1.1 전투에 덧붙은 것 (원본 대비)

| 영역 | 제로식의 확장 | 평가 |
|---|---|---|
| 스탯 5종 | STR(최대HP·근접·핸들) / INT(**패턴 수**·SP·마법) / DEX(핸들·원거리) / SPD(턴 간격) / LUK(소환·회피·크리 미소) | 각 스탯에 **전투 외 역할**(핸들·패턴 수)을 붙여 분배 고민을 만들었다 |
| **패턴 수 = INT+SPD** | INT 10/15/30/50/80 구간마다 패턴 +1 | **스탯으로 수칙 공간을 산다.** 우리도 같은 방식으로 확정 (INT 10/20/35/50/70 구간, 2026-09-10) |
| 핸들(Handle) | 장비 착용 제한 자원. STR·DEX 로 증가 | 장비 = 무게 트레이드오프. 강한 장비를 들려면 스탯을 희생 |
| 진형 | 전열: 방어숙련 1/3 효율(최대 33% 감소) / 후열: 1/2(최대 50%) / **대열변경 스킬** / 전후열 교차 공격 | 후열이 방어 효율이 더 좋다는 역발상. 대열변경이 전술 축이 됨 |
| 스킬 분류 | Magic / Hybrid(물+마) / **Invalid(전열 무시 광역)** / **Backattack(후열 우선)** / 전후열 교차 | 우리 `ignoreCover`, `prefer: backRow` 와 동일 개념. 독립적으로 같은 결론 |
| 속성 8종 | 화·전·냉·풍·지·성·암·하이브리드 + 강화/저항/부여 % | 깊이는 늘지만 정보량 폭발. 신규 진입 장벽의 주범 중 하나 |
| 특수능력 | 완전방어(최대 65%) · 명중 보정 · 방어무시 · 크리 확률/배율 · 닷지 · HP/SP 흡수·재생 · **시전 감소** · **딜레이 공격** | 대부분 장비 옵션으로 붙는다. 우리 "특성" 후보 목록으로 유용 |
| **딜밀기** | 연타 스킬로 상대 턴을 밀어 행동을 봉쇄 | **게이지 조작의 위험 사례.** 초기엔 관광 수준 → 저항 옵션 추가 → 고딜레이 템으로 재부상. 운영자가 비공식 금지 |
| 레벨/스탯 | 레벨 60, 스탯당 250, 레벨당 +5/+2 | 원본 관찰값 유지 |

### 1.2 직업 — 37개 최종직

1차 5계열(전사·마법·성직·활·특수) → 2차 → 3차. 2차 전직 레벨 15, 3차 25~50 + 일부 전직 아이템.
**영웅직은 파티당 1명 제한.** 특수직에 몽크(연계 게이지) · 코만더 · 수학자(영웅) 같은 변종.

**평가**: 37개는 15년 누적의 결과이지 설계 목표가 아니다. 메타는 결국 "소셜나이트 + 카디널 + 마딜"로 수렴했다.
우리 [ADR-003](04_직업트리_PvP_결정.md)의 "2단 유지, 수칙 훅으로 폭 확장"을 재확인. 단 **"파티당 1명" 특수직**은 좋은 편성 제약 장치.

### 1.3 장비 · 제작

- **제련**(8강부터 옵션 부여, 안전제련 4강), **리메이크**(옵션 유지 + 카드 옵션 + 랜덤 추가), **카드**(합성 가능)
- 추가옵션 예: 킬러(공+30, 명중+3%) · 가디언(HP+255, 완방+3%) · 헌터(DEX+25, SPD+15) · 소울콜렉트(SP+150, 흡수+10%)
- **페널옵션**: 마이너스 스탯이 붙는 대신 값이 싸다
- 유니크 세트 7종+ (탱커/딜러/소환/하이브리드/범용), 세트마다 역할 명확
- **보또**: 상자 → 티켓 → 교환. 명백한 도박. 유저 평가 부정적

### 1.4b 공식 매뉴얼 · 게임데이터 직접 관찰 (2026-09-10, hof.zerosic.com)

> 매뉴얼 본문은 **원본 HOF 매뉴얼의 한글판**이다 (사이트 스스로 "meph.koreahosting.co.kr 배포 한글판 소스 개조, 아래 매뉴얼은 원래 소스 기준"이라 명시).

### 1.4c 스킬 208종에서 본 "효과의 종류" (이름·수치는 기록하지 않음)

> `?gamedata=job` 에 스킬 208종이 `대상 - 범위 / SP / 위력%×타수 / 계열 / (선딜:후딜) / 부가효과` 서식으로 공개되어 있다.
> 우리 프리미티브 8종으로 표현 **불가능한** 효과 종류만 추린다 — M2-0/M2 프리미티브 확장 후보.

| 효과 종류 | 설명 | 빈도(대략) | 우리 프리미티브로 |
|---|---|---|---|
| **열 이동** | 자신/대상을 전열화·후열화. "전열일 때 위력 3배 + 자신 후열화" 같은 히트앤런 | 23 | ❌ 없음 → `moveRow` 프리미티브. 진형이 **전투 중에 변하는** 축이 열린다 |
| **열 조건부 위력** | "자신이 후열이면 전열 대상 위력 4배", "자신이 전열이면 2배" | 9+ | ❌ → 효과에 `when: { selfRow / targetRow }` 조건 |
| **연타 점감** | 다단 히트마다 위력 20~50% 감소 | 14 | ❌ → `damage.falloff`. 딜밀기·폭딜 억제 장치 |
| **시전 방해(Delay−x%)** | 대상 게이지를 밀어 영창 취소/지연 | 14 | ⚠ `modifyGauge` 있음. 누적 상한 필요 (07 §3.0) |
| **고속 행동(F.Delay, 후딜 음수)** | 사용 후 다음 차례가 **빨리** 옴 (후딜 −60 ~ −350) | 15 | ⚠ `stiff` 음수 허용하면 됨. 연속 행동 빌드 |
| **무기 제한(Limit:…)** | 특정 무기·방패 착용 시만 사용 (전체 스킬의 1/3) | 67 | ❌ → 스킬 `requires.weaponType`. M2-4 장비와 연결. **장비 선택이 곧 스킬 선택** |
| **쿨다운 / 전투당 1회** | Cool Down: N Turn, Limit:1 | 17 | ❌ → `cooldown`, `perBattle`. 특성 시스템과 같은 장치 |
| **사용 조건** | "HP 25% 이하일 때 사용 가능" | 소수 | ⚠ 수칙 조건으로 대체 가능하나, 스킬 고유 제약은 별도 필드가 명확 |
| **SP 피해 / SP·HP 흡수** | 대상 SP 를 깎거나 비례 피해, 흡수 | ~10 | ❌ → `damageSp`, `drain`. 마법사 상대 카운터 축 |
| **비율 코스트** | 사용자 최대 HP −1% 같은 HP 코스트 | 소수 | ❌ → `costHpPct` |
| **명중률 ±** | 명중 −30% 페널티 | 소수 | ✗ 도입 안 함 (결정론) — 대신 "연타 점감"으로 리스크 표현 |
| **변신(1회)** | 스탯 대폭 상승 + 조건부 | 소수 | ✗ M3 |
| **속성(Fire/Ice/Thunder/Holy)** | 계열별 강화·저항 | 다수 | ✗ 보류 (§3.2) |
| **보스 타입 면역/감소** | 소환·즉사류 보스 무효 | 소수 | → 몬스터 플래그 `bossImmune` (M2-5) |

**핵심 발견**: 원본의 진형은 정적(전열/후열 고정)이었는데, 제로식 15년의 스킬 확장에서 가장 많이 늘어난 것이
**"열을 바꾸는" 효과와 "열에 따라 달라지는" 효과**다. 2열 진형이 정적이면 얕고, 동적이면 전술 축이 된다.
→ M2-0 에서 `moveRow` 와 열 조건부 위력을 프리미티브로 추가할 가치가 크다. 수칙 조건에는 이미 `selfRow`, `teamRowCount` 가 있어 바로 맞물린다.

### 1.5 15년 뒤에 망가진 것 — 우리가 피할 것

1. **인플레이션**: 아이템 수천만 골드. 싱크 부재 → 오브(월간 소멸)로 뒤늦게 대응
2. **노가다**: 자택 일일퀘스트 4시간, 제작 반복
3. **정보 비대칭**: 속성 8종·특수능력 수십 종·37직업 — 신규 유저가 진입 불가
4. **운영자 독재**: 딜밀기 비공식 금지, 보스 일방 너프. 규칙이 게임 안이 아니라 운영자 머릿속에 있음
5. **저작권 불안정**: 우리가 코드·리소스를 따로 만드는 이유

## 2. 유니콘 오버로드 (Vanillaware / Atlus, 2024)

> **일부는 작성자의 사전 지식**이며 해당 항목에 †표기.

**왜 중요한가**: 이 장르의 코어("조건 → 행동" 전술을 짜고 자동 전투를 본다)로 **2024년에 100만 장을 판** 콘솔 게임이다.
메타크리틱 86~89. "수칙 짜기가 재미있는가"라는 M1의 질문에 시장이 먼저 답한 사례.

### 2.1 전투 구조

| 항목 | 유니콘 오버로드 | 우리 |
|---|---|---|
| 유닛 | 최대 5명 (초반 2명, Honors 로 슬롯 해금), **2열 × 3칸 격자** | 5명, 전열/후열 |
| 사거리 | 근접은 전열 우선 타격, 원거리·마법은 어디든 | 엄호 + `ignoreCover` |
| 행동 순서 | 이니셔티브(속도) 순으로 액티브 스킬 | 게이지(ATB) |
| **AP / PP** | 액티브 스킬은 AP(빨강), **패시브 스킬은 PP(파랑) 소모 + 트리거(피격 등)에 반응** | 패시브 없음 → **M2-0 특성 설계에 직접 참고** |
| 종료 | **양측 AP 소진 또는 한쪽 전멸** | 전멸 또는 행동 수 상한 + 연장전 |
| 상성† | 기병 > 보병 > 궁병 > 비행 > 기병, 중갑은 물리 저항 | 없음 (검토 항목) |

**AP 소진 종료**가 핵심 차이다. 전투가 짧고(수십 초), 결착이 안 나면 **양쪽 피해 상태로 끝나 맵에서 다시 만난다.**
우리는 결착까지 가는 대신 연장전으로 무한 힐 대치를 끊는다. 웹/비동기에서는 우리 방식이 맞지만,
"전투당 행동 횟수 상한"을 **자원**으로 보이게 하는 UO 의 표현 방식은 배울 만하다.

### 2.2 Tactics — 우리 교전 수칙과 거의 같은 구조

- 스킬마다 **우선순위 + 조건 최대 2개(AND)**. 위에서부터 평가, 처음 만족하는 것 실행
- **조건 없는 행동을 맨 아래에** 두라고 공식·커뮤니티 모두 권장 → 우리 과제 2 "fallback" 과 동일한 교훈
- 조건은 **발동 조건이자 대상 필터**. TheGamer 는 "Back Row" 와 "**Prioritize** Back Row" 태그의 차이를 별도로 설명
  → 우리 **한정형(require) / 선호형(prefer)** 구분과 정확히 대응. 독립적으로 같은 결론
- 조건 예†: 최저/최고 HP · 후열/전열 · 중갑·비행·기병 등 클래스 타입 · 성별 · 상태이상 보유 · 자신의 N번째 행동 · 아군/적 수 · 확률 · 능력치 최고/최저
- **의도적으로 뺀 조건이 있다** (분석글): 모든 것을 표현할 수 있으면 퍼즐이 사라진다. 조건 2개 제한도 같은 이유
- **Optimize 버튼**: 전술·장비 자동 설정. 초보 이탈 방지 장치 (사용하면 수동보다 약함)
- 커뮤니티 불만: 두 조건의 평가 순서가 명시되지 않아 혼란 → **우리는 AND/OR/NOT 을 명시적으로 노출한다**

### 2.3 성장 · 경제

- 클래스 승급(Rank up) 에 **Honors**, 용병 고용에 Honors, 장비에 Gold, Honors 사용 권한은 **Renown** — 3화폐
- 장비는 슬롯 3~4, 액세서리에 패시브 스킬이 붙는 경우 있음†
- 맵 자유 탐색 + 거점 해방 (우리 의뢰소와 다른 축. 스토리 게임)

### 2.4 우리와의 포지셔닝

| | 유니콘 오버로드 | 우리 |
|---|---|---|
| 형식 | 콘솔 싱글, 스토리, 실시간 맵 | 웹/모바일, 비동기, 반복 최적화 |
| 전술 표현력 | 조건 2개 AND | 조건 무제한, AND/OR/NOT, 16종+ |
| 검증 도구 | 없음 (실전만) | 훈련장 100회 승률, 패인 진단 |
| 공유 | 없음 | 수칙 공유(예정) |
| 엔드게임 | 스토리 완료 | 투기장 PvP (M3) |

**결론**: 코어는 같고, 우리는 "전술을 더 깊게 + 검증 도구 + 공유 + PvP"로 간다. UO 가 증명한 것은 **이 코어가 대중에게 팔린다**는 것이고,
UO 가 안 한 것이 우리의 자리다.

### 3.1 채택 (M2-0 / M2 에 반영)

| # | 항목 | 출처 | 반영 위치 |
|---|---|---|---|
| 1 | **패시브 = 트리거 + 자원(전투당 횟수)** | UO PP | M2-0 특성 시스템: `trigger`(피격/공격/턴 시작/사망) + `perBattle` 상한 |
| 2 | **뽑기 천장** | 제로식 소울 에코 | M2-4 제작: 특성 미부여 N회 누적 시 확정 |
| 3 | **훈련장 상대 세분화** | 제로식 허수아비 16종 | 훈련장에 "시전 허수아비(끊기 연습)", "보스형(고HP)", "N턴 생존" 추가 |

| 5 | **패턴 슬롯 = INT** | 제로식 패턴 수 | ✅ 구현: 기본 4 + INT 10/20/35/50/70 마다 +1. 스탯 분배에 "수칙 공간"이라는 선택지 |
| 6 | **파티당 1명 제한 직업** | 제로식 영웅직 | M2-5 전직: 2차 직업 중 1~2개에 "단일 편성" 제약 |
| 7 | **특성 후보 목록** | 제로식 특수능력 | 시전 감소 · 엄호 피해 감소 · 방어무시 · HP/SP 흡수 · 재생 · 후열 대상 피해 증가 |
| 8 | **Optimize 류 초보 장치** | UO | M2 미결정 4번(자동 분배)에 근거 추가. "쓰면 수동보다 약하다"가 조건 |

## 4. 한 줄 요약

- **제로식**은 "이 장르를 15년 굴리면 무엇이 필요해지고(허수아비·천장·싱크) 무엇이 망가지는가(인플레·정보 폭발·운영 독재)"를 보여준다
- **유니콘 오버로드**는 "이 코어가 2024년에 100만 장 팔린다"를 보여주고, 우리와 **거의 같은 수칙 구조(우선순위·조건·fallback·선호/한정)** 에 독립적으로 도달했다
- 우리 자리는 **더 깊은 전술 표현 + 검증 도구 + 공유 + PvP**, 그리고 둘 다 못 가진 **웹/모바일 비동기**
