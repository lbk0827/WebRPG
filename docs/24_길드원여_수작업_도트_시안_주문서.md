## 0. 왜 다시 찍는가 — 지금 버전이 흐린 원인

지금 `assets/units/guildMember-female.px` 는 원화(`art-source/units/guildMember-female-source.png`, 캐릭터 키 500px 이상)를
[`tools/png-to-px.mjs`](../tools/png-to-px.mjs) 로 48×64 까지 자동으로 줄인 것이다. 8배로 키워 보면 이렇다.

| 부위 | 증상 | 원인 |
|---|---|---|
| 은 흉갑 | 흰 점과 검은 점이 섞인 얼룩 | 줄이면서 경계가 합쳐지고, 금속이 공용 3색(`w` `s` `S`)과 외곽선 `k` 사이를 오간다 |
| 검 | 날이 점선처럼 끊긴다 | 1픽셀 폭의 대각선이 축소에서 살아남지 못한다 |
| 얼굴 | 눈·입이 거의 안 보인다 | 원화가 **약 6등신**이라 52줄 안에서 얼굴이 8칸 남짓 |
| 머리카락 | 낱점으로 흩어진다 | 휘날리는 가닥이 덩어리가 아니라 점으로 줄어든다 |
| 실루엣 | 바깥 외곽선이 끊겨 윤곽이 무너진다 | 자동 변환은 외곽선을 일부러 두르지 않는다 |
| 금발 | 한때 피부와 같은 색이 됐다 (커밋 `5b7ebdc`) | 13종 **공용 팔레트 12색**으로 가장 가까운 색에 끼워 맞춘다 |

즉 원인은 셋이다 — **자동 축소**, **공용 12색 팔레트**, **도트에 맞지 않는 원화 비율.** 이번 시안은 셋을 모두 피한다.

## 2. 보고 찍을 것

### 2-1. 화풍 레퍼런스 — 단장 제공

`art-source/reference/jrpg-sprite-style.png` (단장이 준 JRPG 스프라이트 모음 한 장)

**화풍만** 참고한다. 레퍼런스의 캐릭터·얼굴·옷·자세를 **베끼지 않는다.** 이 그림에서 가져올 것은 아래 다섯 가지뿐이다.

1. 실루엣 둘레의 **어두운 외곽선**이 끊기지 않는다
2. 재질마다 **3단 명암**(밝음 · 중간 · 그늘)에 금속은 **하이라이트 한두 점**
3. 머리카락이 가닥이 아니라 **3~8칸 크기의 색 덩어리** 몇 개로 나뉜다
4. **큰 머리** — 얼굴이 1배에서도 읽힌다
5. 캐릭터 한 명이 **16색 이상**을 쓴다. 평면 스티커가 아니다

### 2-2. 디자인 원화 — 우리 것

`art-source/units/guildMember-female-source.png` 의 **왼쪽 첫 칸**. 여기서 가져올 것은 **디자인 정보**다. 비율과 자세는 가져오지 않는다 (§3-2).

| 부위 | 원화의 디자인 |
|---|---|
| 머리 | 긴 애쉬 금발, 등 뒤로 넓게 흐른다. 앞머리가 이마를 덮는다 |
| 얼굴 | 갈색 눈, 옅은 미소 |
| 망토 | 파란 망토, 목에 두르고 먼 쪽(화면 왼쪽)으로 흘러내린다. 가슴에 금색 둥근 여밈 |
| 상체 | 은빛 흉갑과 어깨 갑옷, 금색 테두리 |
| 허리 | 갈색 가죽 벨트와 허리 주머니, 은 버클. 앞에 흰 천이 무릎 위까지 |
| 다리 | 남색 바지, 은 무릎 보호대, 갈색 장화에 은 발끝 |
| 손 | 은 장갑 |
| 무기 | **에고 소드** — 곧은 한손검, 흰 날, 금색 날밑, 날밑 가운데 **파란 눈 보석** |

길드원(남) `assets/units/guildMember-male.px` 과 **같은 옷 · 같은 대표색 · 같은 무기**다 (docs/21 §0-3). 옷을 바꾸지 않는다.

## 3. 규격

### 3-1. 바꾸지 않는 것 — 게임 화면이 여기에 의존한다

| 항목 | 값 | 어기면 |
|---|---|---|
| 상자 | **48×64** | 편성 판·전투판 배치가 전부 어긋난다 |
| 대기 자세 키 | **52줄** — 머리 꼭대기 `y=8`, 발바닥 `y=59` | 13캐릭터 중 혼자 크거나 작다. 머리카락 꼭대기가 `y=8` 이다 |
| 발 | 발의 가로 중심 `x=24` (상자 기준) | 옆 칸 캐릭터와 겹친다 |
| 시점 | **3/4 반측면, 화면 오른쪽을 본다** | 적 팀 반전이 깨진다 |
| 무기 | 가까운 팔(화면 오른쪽)에 **세워 들거나 내려 든다.** 머리 위로 들지 않는다 | 대기 자세가 공격 자세로 보인다 |
| 뻗는 부분 | 상자 밖으로 나가면 격자를 넓히고 `@canvas 48x64` · `@origin <x> <y>` 를 고친다. **자르지 않는다** | docs/15 §2 |
| 레이어 | `@layer pose0` `pose1` `pose2` (전신 방식) | `build-units.mjs` 가 거부한다 |
| 투명 | `.` = `none` | |
| 화면 배율 | 1배(48×64) · 2배(96×128) 만 | 이미 CSS 에 `image-rendering: pixelated` 가 있다. 건드리지 않는다 |

지금 파일은 격자 65×64, `@origin 7 0` 이다. 새 `pose0` 이 더 좁아지면 `pose1` · `pose2` 를 위해 격자 크기는 그대로 둔다.

### 3-2. 이 시안에서 새로 정하는 그림 규칙

| 항목 | docs/15 (지금) | **이 시안** |
|---|---|---|
| 색 수 | 8~12색 | **16~24색** (투명 제외) |
| 팔레트 | 13종 공용 12색에 스냅 | **이 캐릭터 전용 팔레트.** 관례 문자(`k` `w` `s` `S` `f` `F` `l` `L` `d` `r` `R`)는 뜻을 지키고 문자를 더한다 |
| 명암 | 재질당 2단 | 재질당 **3단** (밝음 · 중간 · 그늘). 빛은 왼쪽 위 |
| 외곽선 | 전부 `k` | **실루엣 바깥은 `k`** 로 끊김 없이. 몸 **안쪽** 경계(흉갑과 망토 사이 등)는 그 재질의 가장 어두운 색 |
| 비율 | 머리 1/3 | 머리(머리카락 포함) **전신의 1/3 가까이, 2.5~3등신.** 원화의 6등신을 그대로 줄이지 않는다 |
| 얼굴 | 눈 2×3 | 눈 **2×3 덩어리**(검은자 + 왼쪽 위 흰 점 1칸), 코는 없거나 1칸, 입 1~2칸. 가까운 쪽 눈은 얼굴 가장자리에 눌려 좁다 |
| 머리카락 | — | 3~8칸 크기의 **색 덩어리 3~5개**. 휘날림은 원화보다 줄여 등 뒤로 두세 갈래만. 외톨이 점 금지 |
| 자세 | — | 원화처럼 다리를 크게 벌리지 않는다. **어깨너비 정도로 서서** 검을 세워 든다. 망토는 먼 쪽으로 짧게 |

**실루엣부터 찍는다.** 순서는 이렇다.

1. `k` 로 실루엣 외곽만 — 머리카락 덩어리 · 망토 · 몸 · 검이 1배에서 구별되는지 본다
2. 재질별 중간색으로 면을 채운다
3. 그늘색 → 밝은색 → 하이라이트 순으로 얹는다
4. 얼굴을 마지막에 찍는다. 1배로 보고 표정이 읽힐 때까지 고친다

### 3-3. 팔레트 제안

색 값은 조정해도 된다. **대표색 `r` / `R` 은 바꾸지 않는다** (`assets/manifest.json` 의 `#315fb2`).

| 재질 | 밝음 | 중간 | 그늘 | 비고 |
|---|---|---|---|---|
| 외곽선 | | `k #1d1d24` | | 공용 그대로 |
| 피부 | `f #f2d3b0` | `g #e0b08a` | `F #b07a5a` | 관례대로 `f` 밝음 · `F` 그늘 |
| 금발 | `H #f0dc9a` | `m #c8b06a` | `h #8a7440` | **피부보다 노랗고, 그늘은 올리브 갈색.** 금발과 피부가 한 덩어리로 보이면 실패 |
| 망토 (대표색) | `b #5a86d6` | `r #315fb2` | `R #214179` | 보석도 이 파랑을 쓴다 |
| 은 금속 | `w #eef2f7` | `s #b9c4d2` | `S #7d8fa6` | 하이라이트는 `w` 한두 점 |
| 금 | `y #e8c05a` | | `Y #a8802e` | 날밑 · 여밈 · 테두리 |
| 흰 천 | `c #f4f0e4` | | `C #c9c0ad` | |
| 남색 바지 | `n #3a4a78` | | `N #262f4e` | 망토 파랑과 섞이지 않게 더 어둡고 탁하게 |
| 가죽 | `l #a8743e` | `i #7a5230` | `L #50341e` | 벨트 · 주머니 · 장화. 관례대로 `l` 밝음 · `L` 그늘 |
| 눈 | | `e #5a3a24` | | 갈색 눈. 흰 점은 `w` |

대략 25색이다. **24색을 넘으면** 흰 천 그늘과 은 그늘, 가죽 그늘과 금 그늘 중 비슷한 쪽을 합친다.
그림자(`d`)는 `pose0` 발밑에 넣지 않는다 — 지금 파일도 그림자를 따로 두지 않는다.
기존 문자(`f` `F` `l` `L` `h` `m` `H`)의 값을 바꾸면 `pose1` · `pose2` 의 색도 조금 바뀐다. 시안 동안은 괜찮다 — 두 자세는 통과 뒤 새로 찍는다.

## 4. 작업 절차

```bash
# 0. 지금 버전을 보관한다 (덮어쓰기 전에)
mkdir -p art-source/units/before
cp assets/units/guildMember-female.px art-source/units/before/guildMember-female.px

# 1. assets/units/guildMember-female.px 의 @palette 를 전용 팔레트로 바꾸고 @layer pose0 을 새로 찍는다
#    pose1 · pose2 에 쓰인 문자는 팔레트에서 지우지 않는다 (지우면 그 칸이 투명이 된다)
#    쓰지 않게 된 옛 문자는 남겨도 된다 — §7 색 수는 pose0 에 실제로 쓰인 문자로 센다

# 2. SVG 로 굽는다
node tools/build-units.mjs

# 3. 10배 확대 시트
node tools/px-to-png.mjs guildMember-female 10

# 4. 게임에서 본다 — 캐릭터 탭 디버그 목록 (주소 끝에 ?debug), 1배와 2배 둘 다
```

**중간 확인 한 번:** 3-2 의 1단계(실루엣)가 끝나면 거기서 멈추고 10배 시트를 올린다. 실루엣에서 틀리면 명암을 얹어도 못 살린다.

## 5. 합격 기준 — 단장이 게임 화면에서 판정한다

**가장 먼저 JRPG 느낌을 본다.** 규격을 다 지켜도 JRPG 느낌이 없으면 반려다.

### 5-1. 반드시 통과

- [ ] **레퍼런스 옆에 놓았을 때 같은 계열로 보인다** — 외곽선 · 3단 명암 · 덩어리 머리카락
- [ ] **지금 버전보다 선명하다** — `before/` 와 나란히, 1배와 2배 둘 다
- [ ] **지금 버전보다 단순해 보이지 않는다** — 선명해졌어도 평면 스티커가 되면 반려 (아이콘 수작업이 두 번 이렇게 반려됐다, docs/14 §9-1)
- [ ] 1배(48×64)에서 **얼굴이 읽힌다** — 눈 두 개가 보인다
- [ ] 1배에서 **검 · 망토 · 긴 금발**이 각각 구별된다
- [ ] 금발과 피부가 **다른 색 덩어리**로 보인다
- [ ] 실루엣 바깥 외곽선이 **끊기지 않는다**

### 5-2. 숫자 검사

- [ ] `pose0` 에 실제로 쓰인 색 **16~24색**
- [ ] 머리 꼭대기 `y=8`, 발바닥 `y=59`, 발 중심 `x=24` (상자 기준)
- [ ] 외톨이 점(상하좌우에 같은 색이 하나도 없는 칸) 거의 없음 — 눈의 흰 점과 금속 하이라이트는 예외
- [ ] `node tools/build-units.mjs` 가 오류 없이 끝난다

### 5-3. 반려

- 원화와 **다른 캐릭터**로 보인다 (옷 · 색 · 무기가 달라짐)
- 레퍼런스 속 **특정 캐릭터를 닮았다**
- 색이 16색 미만이거나 재질이 한 색으로 칠해졌다
- 머리를 검 위로 들었거나 정면을 본다
