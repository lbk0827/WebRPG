## 1. 매뉴얼 (`?manual`) — 원본 HOF 규칙

### 1.1 게임의 목적 (원문 요지)
- **랭킹 1위가 되는 것, 그리고 지켜내는 것.** "모험적인 요소 따윈 없다."
- 1~5명 파티를 편성해 싸우게 하고, 몬스터로 캐릭터를 키우고 아이템을 모아 랭킹을 올린다. 랭킹 상대는 다른 유저.
- 기술 사용 조건을 상세히 설정할 수 있게 만든 결과 "미칠 듯이 귀찮은 게임이 되어버렸다"(개발자 자평)

> 우리에게: 원본의 정체성은 **PvP 랭킹**이고 육성은 수단이다. 우리가 육성(M2)을 먼저 하는 건 인구·서버 문제 때문이며, 최종 정체성은 같다.

### 1.2 메뉴
Top(캐릭터 일람) · Hunt(몬스터 전투) · Item · Shop(구매 + **아르바이트**) · Rank · Recruit(고용) · Setting · Log(과거 전투 로그).
하단에 팀명 · 자금 · **시간(Time)** — 전투·알바로 소모, 시간이 지나면 충전.

### 1.3 전투의 흐름
1. 스탯에 따라 캐릭터가 순서대로 행동한다
2. 미리 설정된 지시(패턴)에 따라 행동한다
3. 반복
4. 종료 조건: 한쪽 전멸, 또는 **합계 100회 턴**에 결판이 안 나면 무승부

전투 도중 유저 개입 없음. 한 번에 끝까지 처리.

### 1.4 스탯 5종
| 스탯 | 역할 |
|---|---|
| Str | 최대 HP, 물리 공격력. DEX 보다 낮은 효율로 핸들 상한 |
| Int | 최대 SP, 마법 위력, **최대 패턴(조항) 수** |
| Dex | 핸들 상한(장비 선택 폭), 궁수 계열 위력. INT 보다 낮은 효율로 패턴 수 |
| Spd | 행동 순서가 돌아오는 간격 |
| Luk | 소환수 강화 |

레벨업 시 포인트를 받아 자유 분배.

### 1.5 행동 패턴(지시) 설정
- 행 번호(No) 순서로 판정 → 부합하면 그 기술 사용. 매 차례 상황이 바뀌므로 상황에 맞춰 행동
- 매뉴얼의 예시: `첫턴행동시 → 기술3` / `자신의 SP 50% 이상 → 기술2` / `반드시 → 기술1`
  → "처음엔 기술3, 이후 SP 50% 이상이면 기술2, 아니면 기술1" (우리 훈련 과제 1·6 과 같은 교훈)
- **조건 행 수는 INT 에 따라 늘어난다**
- 행동에는 기술 외에 **"회복마법", "아이템을 사용한다"** 가 있다
- 조건값은 자유 입력이 아니라 **드롭다운 프리셋**(HP/SP 10~90% 10단계, 평균 10/30/50/70/90, 인원 1~4)

### 1.6 위치와 후열 지키기
- 전방(Front) / 후방(Back). 전투 중 상대와 뒤바뀌면 앞뒤가 교대
- 전방 캐릭터의 **후열 지키는 방법**: 반드시 / 지키지 않는다 / 자신 체력 25·50·75% 이상이면 / 25·50·75% 확률로
  → 우리 엄호 방침과 동일 세트

### 1.7 장비와 핸들
- 캐릭터마다 **handle 상한**, 장비마다 handle 값. 장비 handle 합 ≤ 상한. DEX 와 레벨로 상한 증가
- 표기 예: 한손검 h:1 / 양손검 h:2 / 로브 h:1~3. `Atk` 물리공격, `Matk` 마법공격, `Def`/`Mdef` 는 `비율+고정` 두 항

### 1.8 그 밖의 항목 (목차)
기술 / 공격의 속성 / 캐릭터의 상태(정상·사망·마비) / 전직 / **Sacrier 의 공격법**(HP 를 소모해 기술 사용, 후열이면 소모 2배) / 랭킹 / 고수용 매뉴얼

## 2. 응용 매뉴얼 (`?manual2`)

### 2.1 다중 조건 — "think over"
- **`think over` 라는 스킬을 습득해야** 조건 여러 개를 묶을 수 있다
- 행의 행동 자리에 `think over` 를 넣으면 **그 행과 다음 행의 조건을 AND** 로 묶는다. 연속하면 3개 이상도 가능
- 조건이 안 맞으면 묶음 전체를 건너뛰고 다음 행으로

> 우리에게: **규칙 언어의 기능이 습득 대상**이라는 발상. AND/OR/NOT · "N회만" · 조항 슬롯을 성장 보상으로 해금하는 안 ([07 §3.0](07_M2_육성_장비_경제_명세.md)).

### 2.2 확률 조합
- 70% 행 + 30% 행을 AND 로 묶으면 0.7 × 0.3 = **21%** — 프리셋에 없는 확률을 만드는 법

### 2.3 방어력 수치
- "**앞은 나누고 뒤는 뺀다**" — `Def:7+15` 는 비율 감소 후 고정 감소. 우리 공식과 동일

### 2.4 "약점 속성과 상태이상이 적은 이유" (목차만 존재, 본문 없음)

## 3. 튜토리얼 (`?tutorial`)

- 순서: 기본 직업 4종 소개(전사·마법사·사제·사냥꾼) → 모집소에서 영입 → 고블린 워리어 사냥 → 패턴 설정(아이템 사용 행 예시) → 장비 강화(Sphere) → 상위 몬스터
- 사냥 단계: 고블린 워리어 10회 → 보어 라이더(**핸들 학습**) → 탱크(**방어 옵션 학습**) → 배틀 마스터(**3시간 리젠, 5회 도전 제한**)
- 패턴 예시: "현재 HP 500 이하일 때 + 1턴마다 필수 → 물 마시기(SP 회복 아이템)"

> 우리에게: **몬스터 자체가 교재**(핸들을 가르치는 몬스터, 방어를 가르치는 몬스터). 우리 07 §3.9 "몬스터도 수칙으로 움직이며 지역이 깊어질수록 정교해진다"와 같은 발상. "도전 횟수 제한 보스"는 행동력 없는 우리 M2 에서 희소성 장치로 쓸 수 있다.

## 4. 게임데이터 — 판정(조건) 목록 (`?gamedata=judge`)

원본 HOF 와 같은 세트. 카테고리와 **값의 단계**만 정리한다.

| 카테고리 | 조건 | 값 단계 |
|---|---|---|
| 기본 | 반드시 / 다음 패턴으로 | — |
| 자신 HP | 이상 / 이하 | 10~90% (10 단위) |
| 아군 HP | N% 이하인 캐릭터가 있을 때 | 10/30/50/70/90 |
| 아군 평균 HP | 이상 / 이하 | 10/30/50/70/90 |
| 자신 SP / 아군 SP / 평균 SP | 위와 동일 구조 | 동일 |
| 생사 | 아군 N명 이상 쓰러짐(1~3) / 혼자만 생존 / N명 이상 생존(2~4) | 인원 |
| 확률 | N% 의 확률로 | 10/30/50/70/90 |
| 행동 순서 | 첫턴 ~ 5턴 행동시 | 1~5 |
| 횟수 | "N번은 반드시"(1~3) | 1~3 |
| 시전 | 아군/적에 차지(영창) 중인 캐릭터가 있을 때 / 없을 때 | 유무 |
| 독 | 독 상태 캐릭터 1 / 2 / 3 / 4명 이상 | 인원 |
| 진형(아군) | 자신이 전방/후방 · 아군 전방/후방 없음 · N명 · N명 이하 · N명 이상 · **전방이 뒤로 빠질 때** | 인원 |
| 진형(적) | 적 전방/후방 있음 / 없음 | 유무 |
| 소환 | 소환 캐릭터 없음 / 1마리만 / 1마리 이상 | 마릿수 |

> 우리 조건 16종은 이 세트를 `side` 파라미터와 자유 입력값으로 압축하면서 AND/OR/NOT 을 더한 것이다.
> 우리에 없는 것: 소환 관련(M3), "전방이 뒤로 빠질 때"(열 이동 도입 시 `rowChanged` 조건 후보).

## 5. 게임데이터 — 아이템 (`?gamedata=item`)

- 분류: 무기(검·양손검·완드·스태프·활) / 방패(방패·책) / 갑옷(갑옷·천·로브) / 아이템(반지·목걸이 — 스탯 가산) / 소재 / 추가 소재
- 표기: `이름 (타입) / Atk / Matk / Def:비율+고정 / Mdef:비율+고정 / h:핸들 / M:재질 / 특수`
- 방패에 **완전 방어(+6~10%)** 옵션, 양손 무기는 `TwoHand` 표기, 책은 방어구이면서 마공
- **Power Sphere**: 장비에 부여하는 추가 소재. 물리 능력 증가 + "패턴에 익숙하지 않은 초보자를 위해 **패턴 추가(+1)**"

> 우리에게: 장비 특성 후보 **"조항 +1"**. 초보 배려를 장비로 푼 사례.

## 6. 게임데이터 — 직업 · 스킬 (`?gamedata=job`)

### 6.1 직업 구조
1차 5계열(전사 · 마법 · 성직 · 활 · 특수직) → 2차(레벨 15) → 3차(레벨 25~50, 일부 전직 아이템). 최종직 37개. 숨겨진 직업 3종. 영웅직은 파티당 1명.
직업별 장착 가능 장비 타입이 화이트리스트로 지정됨 (원본과 같은 구조, 타입 수가 훨씬 많음 — 채찍·악기·권총·수리검·완갑 등).

### 6.2 스킬 서식
`이름 / 대상 - 범위 / 소비SP / 위력%×타수 / 계열(Physical·Magic·Hybrid) / (선딜:후딜) / 부가효과`
- 대상: enemy · friend · self · all / 범위: individual · multi · all
- `★` = 상위 스킬, `invalid` = 전열 무시, `Limit:무기` = 무기 제한, `Cool Down: N Turn`, `Limit:1` = 전투당 1회

### 6.3 스킬 208종의 "효과 종류" (빈도)
이름·수치 없이 종류만. 상세와 우리 프리미티브 대응은 [08 §1.4c](08_참고_제로식_유니콘오버로드.md).

| 효과 종류 | 빈도 |
|---|---|
| 무기 제한 (Limit:) | 67 — 전체의 1/3 |
| 전열 무시 (invalid) | 58 |
| 하이브리드(물+마) 계열 | 25 |
| 열 이동 (후열화 16 · 전열화 7) | 23 |
| 소환 관련 | 18 |
| 쿨다운 | 17 |
| 고속 행동 (F.Delay, 후딜 음수) | 15 |
| 시전 방해 (Delay−) | 14 |
| 연타 점감 | 14 |
| 독 | 12 |
| 열 조건부 위력 ("전열일 때 N배") | 9 |
| 명중률 조정 | 8 |
| HP/SP 흡수 · SP 피해 | ~10 |
| 리젠 | 4 |
| 교차 공격(전열→후열) | 4 |
| 변신 | 3 |
| 사용 조건("HP 25% 이하일 때") | 3 |

## 7. 한 줄 요약

원본 매뉴얼은 우리가 이미 관찰한 것의 확인이고, 제로식 고유 정보에서 **바로 쓸 것은 셋** —
① AND 는 배우는 능력(`think over`) → 규칙 기능 해금 ② 장비가 조항 +1 ③ 15년간 가장 많이 늘어난 스킬 효과는 **열 이동**.
