## 0. 원본 소재에 대한 결론

원본 저장소를 확인한 결과 캐릭터 이미지는 **사실상 존재하지 않는다**
(`image/char/` 에 gif 2장과 `NoImage.gif` 뿐). ReadMe 에 따르면 캐릭터·아이콘은
제3자 소재 배포 사이트(Rド, Whitecat)에서 받아 파일명만 맞춰 쓰는 구조였다.

따라서:
- "참고할 원본 이미지" 자체가 거의 없다
- 있다 해도 그 소재들은 **각자의 배포 규약(대부분 비상업)** 을 따르므로 사용 불가
- **"보고 변형해서 그리는 것"도 2차적 저작물** — 코드보다 판단 기준이 엄격하다

→ 이미지는 전량 **자체 제작 또는 상업 이용 가능 소재**로 간다. 예외 없음.

## 2. R1 직업 아이콘 — 설계 기록

### 직업 5종과 엔진 프리셋 매핑

| 아이콘 | 직업 | 엔진 preset id | 역할 | 이전 프리셋에서 |
|---|---|---|---|---|
| 🛡 검+방패 | 전사 | `warrior` | 전열 방벽 · 타격 | 방벽병 + 검사 통합 |
| 🗡 교차 단검 + 독 | 도적 | `rogue` | 끊기 · 독 · 연타 | 교란자 + 광전사 통합 |
| 🔮 지팡이 + 보주 | 마법사 | `mage` | 후열 광역 마법 | 마법사 그대로 |
| ✨ 성배 + 광휘 | 프리스트 | `priest` | 회복 · 소생 · 보호 | 사제 그대로 |
| 🏹 활 + 화살 + 잎 | 엘프 | `elf` | 후열 관통 사격 | 궁수 그대로 |

> "엘프"는 엄밀히는 종족이지만, 이 장르의 한국 유저에게는 **궁수 계열 직업명**으로 통용된다.
> 세계관상 "용병단에 고용된 엘프 사수" 정도로 두면 어긋나지 않는다.
> 프리스트는 종교 상징(십자가 등)을 피하고 **성배 + 빛**으로 표현했다.

## 4. 전투 스테이지 (M2) — 시각적 전투 연출

**결정 (2026-09-10)**: 전투 연출은 M2 에 만든다. M1 은 텍스트 타임라인만.
연출은 M1 의 질문("수칙 짜기가 재미있는가")에 답하지 않고 오히려 가린다.

**나중에 붙여도 싼 이유**: 엔진 출력이 이벤트 로그이므로, 연출은 같은 로그를 다른 렌더러로 재생하는 것이다.

```
simulate() → 이벤트 로그 ─┬→ 타임라인 렌더러 (M1)
                         └→ 스테이지 렌더러 (M2): 스프라이트 + CSS 애니메이션
```

**M1 에서 지킬 것 하나**: 보고서 뷰어를 **이벤트 재생기(커서·속도·건너뛰기) + 렌더러**로 분리한다.
M2 는 렌더러만 하나 추가한다. 재생기는 다시 만들지 않는다.

**2026-09-10 스테이지 렌더러 1차 완료** (`apps/web/src/components/Stage.tsx`).
계획대로 재생기(`Replay.tsx`)의 cursor 위에 렌더러만 얹었다. 엔진·과제·재생기는 변경 없음.
- 현재 턴의 이벤트 슬라이스 → 연출: 돌진(행동자) · 흔들림(피격) · 팝업(피해/회복/상태/엄호/끊김/소생)
  · 말풍선("N번 조항 · 스킬" / "…우물쭈물" / "시전…" / "발동!") · 시전 표시 · 사망 탈색
- 전부 CSS 애니메이션. 스프라이트는 SVG 배지 그대로 — 진짜 그림은 파일 교체만으로 들어간다
- 재생 속도에 따라 돌진 길이가 줄어든다 (`--turn-ms`). `prefers-reduced-motion` 존중
- 텍스트 보고서는 "보고서" 토글로 스테이지 아래에 남겨둠 — 디버깅 도구는 사라지지 않는다

### 스테이지 구성 (아이디어 레벨)
- 5 vs 5, 전열/후열 두 줄이 마주 봄
- 공격 = 전방 돌진 후 복귀, 피격 = 흔들림, 시전 = 머리 위 게이지, 사망 = 탈색
- 데미지 팝업, HP/SP 바
- **말풍선에 "N번 조항"** — 연출 위에 디버깅 정보를 얹는다. 시각적 전투가 보고서를 겸하게 된다
- DOM + CSS transform 으로 구현. PixiJS 는 파티클/대규모 개체가 필요해질 때만

### 스프라이트 요구사항 (직업당 4상태)

| 상태 | 용도 |
|---|---|
| `idle` | 대기 |
| `attack` | 공격 · 시전 순간 |
| `hit` | 피격 |
| `dead` | 사망 |

- **1차 스프라이트 = 지금의 SVG 배지 그대로.** 배지가 돌진/흔들림만 해도 "누가 누구를 때렸는지"는 읽힌다
- 매니페스트가 `preset id → { idle, attack, hit, dead }` 를 가리키게 하면, 진짜 캐릭터 그림은 **파일 교체만으로** 들어간다
- 몬스터 스프라이트는 PvE 도입 시. M1·M2 훈련 과제의 적은 같은 5직업이라 재사용
