# 30. 승급 시험 — 레벨을 지운 문제형 전투 (기획)

2026-09-17 · 상태: **기획 확정 (단장 결정 4건 §9), 구현 전**

> 이름은 **승급 시험**으로 정했다 (§9-4). 아래 본문의 "시험 전투"는 같은 것을 가리킨다.

> **승급 시험 (시험 전투)**: 상대가 고정되어 있고, 출전 단원을 **정해진 레벨로 맞춰서** 싸우는 전투.
> 레벨로는 못 넘고 수칙으로만 넘는다. 모험 탭에 붙는다.

---

## 1. 왜 필요한가

이 게임의 실력은 "설계 능력"이다 (docs/13 §1). 그런데 측정해 보니 초반에는 이 말이 성립하지 않는다.

- docs/18 §8: Lv6 에서 레벨 5 는 분배 포인트를 **두 배로** 만든다. 어떤 수칙도 이걸 못 이긴다
- 그래서 초반(Lv1~15)은 "레벨이 보상인 구간"으로 두고 부등식을 요구하지 않기로 했다
- 문제는 **첫인상이 이 구간에서 생긴다**는 것이다. 새 플레이어는 "수칙을 고치느니 레벨을 올리는 게 낫다"고 배운다

일반 전투(지역 반복)는 그대로 둔다. 초반에 레벨이 보상인 것은 맞다.
대신 **레벨 레버를 아예 지운 전투**를 따로 둔다. 레벨을 지우면 남는 것은 수칙뿐이다.

훈련 과제(missions.ts)가 이미 같은 일을 한다 — 고정 편성, "기본 수칙은 지고 정답은 이긴다".
시험 전투는 그것을 **내 단원으로** 하는 것이다. 훈련 과제가 개념 하나를 가르치면,
시험 전투는 개념 두 개를 묶어 **졸업 시험**을 본다. 할 일 #3(퀘스트형 튜토리얼)의 마지막 칸이 된다.

---

## 2. 규칙

### 2.1 레벨 동기화

> **레벨 동기화**: 출전 단원의 능력치를 그 시험의 기준 레벨 기준으로 다시 계산하는 것.

| 항목 | 처리 | 이유 |
|---|---|---|
| 레벨 | 기준 레벨보다 높으면 **내린다**. 낮으면 그대로 | 올려 주면 낮은 레벨의 지름길이 된다. 해금 조건이 레벨 하한을 보장한다 |
| 분배 스탯 | 분배한 **비율은 유지**하고 총량만 기준 레벨의 포인트 `(L−1)×5` 로 줄인다 (정수 내림) | 스탯 빌드도 설계다. 비율을 지우면 분배의 의미가 사라진다 |
| HP · SP | `growthStats(base, L, alloc)` 로 다시 계산 | 엔진에 이미 있는 함수 그대로 |
| 패턴 칸 | 줄어든 INT 로 다시 계산 | 칸 수는 INT 가 정한다 (원칙 2). 칸이 모자라면 **아래 줄부터 꺼진 채로** 출전하고 화면에 알린다 |
| 배운 스킬 | 그대로 | 무엇을 배웠는가가 설계다 |
| 장비 | **수치 보정은 끄고 특성만 남긴다** | 원칙 5 — 단순 수치는 스탯이 하고, 장비는 수칙과 맞물리는 것만 남는다 |
| 전직 | 기준 레벨이 15 미만이면 **1차 직업으로** 싸운다. 2차 스킬·훅은 빠진다 | 전직 훅이 초반 시험을 공짜로 풀어 버리는 것을 막는다 (§9-1 결정) |

### 2.2 그 밖의 규칙

- **상대 고정 · 시드 고정.** 훈련 과제와 같다. 같은 수칙이면 같은 결과가 나오므로, 수칙만 바꿔 다시 싸우면 **무엇이 달라졌는지 바로 보인다** (§5)
- **재도전 대기 없음.** 문제를 푸는 곳이지 보상을 캐는 곳이 아니다. 대신 보상은 **첫 합격 때만** 크게 준다 (§7)
- **해금**: 해당 지역 3승 + 기준 레벨 이상인 단원이 편성에 있을 것

## 3. 시험 3종 (초반)

사전 확인한 엔진 사실 두 가지가 설계의 바닥이다.

- **시전을 취소하는 수단은 침묵(`hush`)뿐이다.** 흔들기(`stagger`)는 게이지를 −500 늦출 뿐이다.
  피해를 받아도 시전은 끊기지 않는다 (effects.ts). docs/13 §5 의 "피해를 받으면 끊긴다"는 설명이 틀려 있어 2026-09-17 고쳤다
- 초반 편성에서 쓸 수 있는 것: 모험가(강타·연타) + 직업 시작 스킬 + 습득 스킬 몇 개

수치는 구현 때 §6 기준을 통과하도록 **측정으로** 정한다. 여기 적는 것은 구조와 함정이다.

### 시험 1 「봉화」 — 가도 · 기준 Lv5

| | |
|---|---|
| 상대 | 도적 두목(전열, 엄호 항상) · 도적단 단검수 · **도적 신호수 ×2** (후열, 신규) |
| 신규 적 기술 | `signalFire` 봉화 — 준비 700 · 적 쪽 전원 공격↑ + 게이지 +300. 기존 효과(`applyStatus`·`modifyGauge`)만으로 만든다 |
| 신호수 수칙 | `SP ≥ 16 → 봉화` / `항상 → 기본 공격` |
| **함정** | 도적 기본 수칙은 침묵이 맨 위라 첫 봉화는 끊는다. 그런데 둘째 줄 **독 바르기가 남은 SP 를 써 버려서**, 신호수 둘이 번갈아 올리는 세 번째 봉화를 못 끊는다 |
| 정답 A | 독 바르기에 `자기 SP ≥ 24` 를 붙여 **침묵 몫을 남겨 둔다** (SP 예약) |
| 정답 B | 엘프의 관통 사격(후열 우선 · 엄호 무시)을 맨 위로 올려 **신호수를 먼저 쓰러뜨린다** |
| 가르치는 것 | 끊기 · SP 를 아껴 두는 조건 (훈련 과제 `interrupt` + `threshold` 의 졸업) |

### 시험 2 「벽 뒤의 목소리」 — 폐허 요새 · 기준 Lv9

| | |
|---|---|
| 상대 | 경쟁 용병 전사 ×2 (**엄호 항상** · 굳히기) · 경쟁 용병 프리스트 (후열 · 치유 주문) · 경쟁 용병 마법사 (후열) |
| **함정** | 적이 넷이라 전사 기본 수칙의 휩쓸기(`적 ≥ 4`)가 **항상 켜진다**. 피해가 넓게 퍼지고, 굳힌 전열에 막히고, 프리스트가 되돌린다. 강타도 엄호에 막힌다 |
| 정답 A | 전사가 **갑주 파쇄**를 배워 `적 중 HP 70% 이상 존재 → 갑주 파쇄` 를 위에 두고, 휩쓸기를 지운다 (한 명에 모은다) |
| 정답 B | 엘프 관통 사격 · 마법사 대화염(엄호 무시)으로 **후열 프리스트부터** 친다 |
| 가르치는 것 | 광역이 늘 옳지는 않다 · 엄호를 뚫는 법. docs/18 §9 에서 "아직 최선 조합에 못 든" **갑주 파쇄에 자리가 생긴다** |

### 시험 3 「방해꾼」 — 고블린 부락 · 기준 Lv14

| | |
|---|---|
| 상대 | 고블린 족장 · 고블린 전사 · **고블린 방해꾼 ×2** (후열, 신규) |
| 방해꾼 수칙 | `적 시전 ≥ 1 → 침묵` / `적 시전 ≥ 1 → 흔들기` / `항상 → 기본 공격` — **플레이어의 끊기 도구를 그대로 쓴다** |
| **함정** | 마법사 기본 수칙은 대화염(준비 600)이 맨 위라 **매번 끊기고** SP 만 날린다. 프리스트의 소생(준비 500)도 끊긴다 |
| 정답 A | 대화염에 `적 생존 ≤ 2` 를 붙인다 — 방해꾼이 쓰러진 뒤에만 큰 기술을 쓴다. 그 전에는 마력탄 |
| 정답 B | 방해꾼의 SP 를 먼저 바닥낸다 — 미끼로 **짧은 시전**(강타, 준비 250)을 먼저 보여 침묵을 끌어낸 뒤 큰 기술 |
| 가르치는 것 | 끊기는 기술은 상황을 봐서 쓴다 (훈련 과제 `nocast` 의 졸업). **몬스터가 교재다** (원칙 3) 를 가장 직접 보여 주는 시험 |

새 몬스터 3종(신호수 ×1 종, 방해꾼 ×1 종 — 같은 종 2마리씩)은 사람·고블린이라
**기존 아이콘·도트(outlawArcher / goblin)를 그대로 쓴다.** 새 그림이 필요 없다.

## 4. 상대 수칙 공개

시험 전투의 핵심은 "읽고 고친다"다. 상대 수칙이 보이지 않으면 읽을 것이 로그뿐이다.

- 시험 화면에 상대마다 **수칙 줄을 가린 채로** 보여 준다 (`??? → 봉화`처럼 스킬 이름만)
- 한 판 싸울 때마다 그 판에서 **실제로 발동한 줄**(`ruleFired` 이벤트)의 조건이 열린다
- 합격하면 전부 열린다. 도감에도 같은 공개 상태가 남는다

엔진은 고칠 필요가 없다 — 이미 나오는 이벤트를 접으면 된다 (`analysis.ts` 와 같은 방식).

## 5. 다시 싸우고 비교하기

시드가 고정이므로 "지난 판"과 "이번 판"은 **수칙만 다르다.** 이것을 화면으로 보여 준다.

- 패배 뒤 결과 화면에 **[수칙 고쳐서 다시]** — 편성 화면을 거치지 않고 해당 단원의 수칙 편집으로 바로 간다
- 두 번째 판부터 **지난 판과 나란히**: 누가 몇 번째 행동에서 무엇을 했는지 달라진 곳만 강조
- 패배 진단 두 줄(원칙 4)에 **해당 수칙 줄 바로 가기** — "신호수의 3번째 봉화를 못 끊었다 · 도적 SP 4 (침묵 12 필요)" → 누르면 도적의 2번 줄

비교 화면은 시험 전투에서 먼저 만들고, 잘 되면 일반 전투의 "같은 조우 다시"에도 넓힌다.

## 6. 합격 기준 (테스트로 고정)

`test/trials.test.ts` 가 시험마다 확인한다. 훈련 과제의 "기본은 지고 정답은 이긴다"를 **시드 여럿**으로 넓힌 것이다.

| 기준 | 값 | 이유 |
|---|---|---|
| 해금 시점 표준 편성 (프리셋 · 시작 스킬 · 장비 없음) + 기본 수칙 | 승률 **≤ 20%** | 안 고치면 못 넘어야 시험이다 |
| 정답 A · 정답 B 각각 | 승률 **≥ 80%** | 답이 운에 기대면 안 된다 |
| 정답의 **축이 둘 이상** | A 와 B 가 서로 다른 단원의 수칙을 고친다 | 답이 하나뿐이면 퍼즐이 아니라 암기다 |
| 동기화 후 레벨 +5 편성 (정답 없이) | 여전히 **≤ 30%** | 동기화가 레벨 레버를 실제로 지웠는지 확인 |

측정 함정 넷(자동 충족 · 포화 · 자리 레버리지 · 상한 해제)을 먼저 확인한다.
특히 시험 1 의 `적 시전 ≥ 1` 은 봉화가 반복되면 **자동 충족**에 가까워진다 — 기본 수칙이 우연히 이기는지 시드별로 본다.

## 7. 보상

- **첫 합격 보상**: 금 + 해당 지역 재료 확정 (스킬 포인트는 주지 않는다 — §9-2)
- 재도전은 보상 없음 (또는 아주 작게). 동기화 전투를 캐는 이유를 만들지 않는다
- 첫 합격 기록은 본부에 **「승급 시험 합격 3/3」** 처럼 남는다
