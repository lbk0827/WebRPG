## 1. 기술 규약

전부 **손으로 쓴 SVG**다 (코드로 생성한 SVG 포함). 래스터 이미지는 받지 않는다.

| 항목 | 값 |
|---|---|
| 형식 | SVG. `<?xml?>` 선언 없이 `<svg>` 로 시작 |
| 루트 | `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 64 64" width="64" height="64">` |
| 첫 자식 | `<title>한국어 이름</title>` — 접근성과 툴팁에 쓰인다 |
| 외곽선 | `#1d1d24` (ink). 굵기 3 (64 기준). `stroke-linejoin="round"` |
| 색 수 | 외곽선 + 채움 **2~3색까지**. 그라디언트·필터·그림자 금지 |
| 텍스트 | 금지. 글자 없이 형태만으로 구분되어야 한다 |
| 파일 크기 | 하나에 2KB 이하 권장 |
| 좌표 | 정수 또는 소수점 한 자리까지 |

**이미 있는 것 (건드리지 말 것)**: `assets/jobs/*.svg` 5종, `assets/monsters/*.svg` 8종.
이 둘은 `viewBox 0 0 128 128` 에 배경 원(r=60)을 쓴다. 새로 만드는 것은 아래 배경 규약을 따른다.

### 배경 모양으로 종류를 구분한다

| 종류 | 배경 | 이유 |
|---|---|---|
| 직업 · 몬스터 *(완료)* | 원 | 사람·생물 |
| **스킬** | 둥근 사각형 (`rx=14`), 계열색으로 채움 | 목록에서 줄지어 나온다 |
| **장비 · 재료** | **배경 없음** (투명). 물체만 | 창고·상점 줄에 얹힌다 |
| **상태이상** | 작은 원 + 굵은 외곽 (4) | 전투 중 캐릭터 위에 12px 로 붙는다 |
| **특성** | 육각형 | 장비에 붙는 수동 효과 |

### 팔레트 (`assets/manifest.json` 의 `palette`)

```

paper   #e9e4d8   밝은 채움
steel   #cfd6e0   금속
leather #8a7550   가죽
wood    #6b4b2a   나무
arcane  #8fd3ff   마법

```

스킬 배경의 **계열색**:

| 계열 | 색 | 해당 |
|---|---|---|
| 물리 | `#b23a48` | 힘·손재주로 때리는 것 |
| 마법 | `#2f6fd6` | 지능으로 때리는 것 |
| 회복·보조 | `#3e8e5a` | 아군을 살리고 올리는 것 |
| 방해 | `#5b4b8a` | 적을 깎고 막는 것 |

### 검수 기준

- **24px 로 줄였을 때 서로 구분되는가.** 실제 사용 크기는 18~40px 다. 세밀한 묘사는 지워진다
- 밝은 바탕(`#f3f0ea`)과 어두운 바탕(`#1d1d24`) 양쪽에서 보이는가
- 같은 종류끼리 한 세트로 보이는가 (굵기·여백·비율)
- 미리보기: `node assets/build-preview.mjs` → `assets/preview.html` 에서 96/48/24px 를 한 번에 본다.
  새 종류를 추가했다면 이 스크립트도 함께 확장한다

## 6. 납품 방법

1. 파일을 위 경로에 놓는다 (`assets/skills/`, `assets/items/`, `assets/status/`, `assets/traits/`)
2. `assets/manifest.json` 에 해당 절을 추가한다 — 기존 `jobs` · `monsters` 절과 같은 형태 (`name`, `icon`, 필요하면 `color`)
3. `assets/README.md` 원장에 파일마다 한 줄 추가
4. `node assets/build-preview.mjs` 로 미리보기를 갱신한다
5. **웹 코드는 건드리지 않아도 된다.** 붙이는 작업은 이쪽에서 한다 —
   경로 규약(`<종류>/<엔진 id>.svg`)만 지키면 된다
