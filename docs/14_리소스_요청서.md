## 1. 기술 규약

> **2026-09-13 단장 결정:** 캐릭터·몬스터 스프라이트와 한 세트로 보이도록 아이콘도 전부 도트 형식으로 통일한다.

전부 처음부터 작은 화면을 전제로 그린 **고전 JRPG식 도트 PNG**다. 큰 원본에서 단순 벡터를 기계적으로 픽셀화하지 않고,
도트 덩어리·계단형 대각선·제한 팔레트를 의도해 생성한 뒤 최근접 방식으로 32×32에 맞춘다.

| 항목 | 값 |
|---|---|
| 형식 | 투명 배경 RGBA PNG |
| 게임용 크기 | **32×32px**. 주 피사체는 약 28~30px 안에 들어오게 한다 |
| 원본 위치 | `art-source/icons/<종류>/<id>-source.png` — 배포 폴더 밖에 둔다 |
| 외곽선 | 매우 어두운 갈색·남색 계열 1픽셀 상당. 순수 검정 한 색으로 모든 재질을 뭉개지 않는다 |
| 색 수 | 8~12색을 목표로 재질별 밝음·기본·그늘을 둔다. 그라디언트·흐림·안티앨리어싱 금지 |
| 텍스트 | 금지. 글자 없이 형태만으로 구분되어야 한다 |
| 축소 | `python tools/process-jrpg-icon.py <원본> <출력>` — 최근접 축소와 알파 임계 처리만 수행 |

기존 벡터 아이콘을 24×24 격자로 변환하던 방식은 폐기한다. 승인 기준은
`art-source/icon-drafts/jrpg-style-proof.png`의 파이어볼·참나무 지팡이 시안이다.

### 배경 없이 실루엣과 색으로 종류를 구분한다

| 종류 | 표현 |
|---|---|---|
| **스킬** | 공격 궤적·마법 효과·행동을 단일 상징으로 표현 |
| **장비 · 재료** | 물체 하나만 분명하게 표현. 같은 장비 계열은 등급에 따라 장식과 재질이 발전 |
| **상태이상** | 12~16px에서도 읽히는 단순하고 강한 상태 상징 |
| **특성** | 효과를 대표하는 물체 또는 행동 상징. 육각 배경을 강제하지 않음 |

모든 종류의 배경은 완전 투명이다. 분류는 UI가 담당하며 아이콘 안에 색 타일이나 배지를 넣지 않는다.

| 계열 | 색 | 해당 |
|---|---|---|
| 물리 | `#b23a48` | 힘·손재주로 때리는 것 |
| 마법 | `#2f6fd6` | 지능으로 때리는 것 |
| 회복·보조 | `#3e8e5a` | 아군을 살리고 올리는 것 |

### 검수 기준

- **32px와 24px에서 서로 구분되는가.** 실제 사용 크기는 18~40px 다. 세밀한 묘사는 지워진다
- 밝은 바탕(`#f3f0ea`)과 어두운 바탕(`#1d1d24`) 양쪽에서 보이는가
- 같은 종류끼리 한 세트로 보이는가 (굵기·여백·비율)
- 미리보기: `node tools/build-preview.mjs` → `tools/preview.html` 에서 96/48/24px 를 한 번에 본다.
  새 종류를 추가했다면 이 스크립트도 함께 확장한다

## 6. 납품 방법

1. 파일을 위 경로에 놓는다 (`assets/skills/`, `assets/items/`, `assets/status/`, `assets/traits/`)
2. `assets/manifest.json` 에 해당 절을 추가한다 — 기존 `jobs` · `monsters` 절과 같은 형태 (`name`, `icon`, 필요하면 `color`)
