# Project_WebRPG (가제)

행동 규칙을 프로그래밍해서 자동 전투로 검증받는 웹 RPG.

**▶ 프로토타입 플레이: https://lbk0827.github.io/WebRPG/**
(`develop` 브랜치에 푸시할 때마다 테스트 → 빌드 → 자동 배포. 폰 브라우저에서도 동작)

## 이 프로젝트가 무엇인가

플레이어는 전투를 직접 조작하지 않는다.
전투 전에 캐릭터마다 **"이런 상황이면 이 스킬을 써라"** 라는 규칙 목록을 작성하고,
그 규칙이 실전에서 어떻게 굴러가는지를 전투 로그로 확인한 뒤 다시 고친다.

실력의 척도는 반사신경이 아니라 **설계 능력**이다.

## 저작권 / 클린룸 정책 ⚠️

이 프로젝트는 일본 웹게임 `Hall of Fame`(Juice/Tekito, 2007-2008)의
**게임 시스템을 아이디어 차원에서 참고**하되, **코드·데이터·리소스는 일절 사용하지 않는다.**

원본은 이용규정에서 **상업적 이용을 명시적으로 금지**하고 있으므로 기반 코드로 쓸 수 없다.
자세한 내용은 [docs/00_클린룸_정책.md](docs/00_클린룸_정책.md) 참조.

- 원본 소스는 이 저장소 **바깥**의 `../_Reference_ReadOnly/` 에 격리되어 있다.
- 그 디렉토리의 파일을 이 프로젝트로 가져오는 것은 **어떤 형태로도 금지**된다.

## 기술 스택 (ADR-001)

- **전투 엔진**: TypeScript 순수 함수 패키지. 정수 고정소수점으로 완전 결정론
- **클라이언트**: React + TypeScript 웹앱
- **서버**: Node + 관계형 DB
- **앱 배포**: 필요 시점에 Capacitor로 래핑 (코드 재작성 없음)
- **게임 엔진(Unity/Godot 등)은 사용하지 않는다** — 이 게임이 그리는 것은 폼과 텍스트지 픽셀이 아니다

## 실행

```bash
npm install
npm run dev                                 # 웹 훈련장 → http://localhost:5173
npm test                                    # 엔진 테스트 (결정론 골든 테스트 포함)
npm run lint                                # Math.random / Date 사용 금지 검사
npm run report -- --a balanced --b rush --seed 7   # 전황 보고서 (콘솔)
npm run train  -- --a balanced --b rush --n 200    # 훈련장: N회 대전 승률
npm run train  -- --all --n 100                    # 전체 팀 대진표
```

### M1이 답하려는 질문

> **"교전 수칙을 짜는 것 자체가 재미있는가?"**

여기서 답이 안 나오면 육성도 경제도 PvP도 의미가 없다.
따라서 M1은 레벨업·장비·경제·PvP를 전부 빼고, 플레이어가 바꾸는 변수를 **수칙과 편성**으로만 제한한다.
